# Permissions

- `herobrinefishing.use`: player commands and menus. Default: everyone.
- `herobrinefishing.admin`: complete administrative command tree and GUI. Default: operators.
- `herobrinefishing.admin.nextfish`: set, inspect, or clear runtime one-shot next-fish overrides. Default: operators and a child of `herobrinefishing.admin`.

`herobrinefishing.use` includes the Bait Loader and Fishing Shop. Use the server permission manager to deny player access or delegate the administrative role. Global reset confirmation is still required even when the sender has administrative permission.
