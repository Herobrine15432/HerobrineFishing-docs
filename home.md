# Home

HerobrineFishing is a focused Paper 26.2 angling plugin. Minecraft still owns casting, the bobber, bite timing, Lure timing, rod durability, Unbreaking, Mending, and Curse of Vanishing. Managed rods replace only the native fish result with a configurable species and an anchor-block fight.

The default product contains 80 fish, six rarities, nine open string-based types, eight native rods, collection/stat tracking, a simple Vault market, optional WorldGuard conditions, operator tools, English/Italian localization, and SQLite persistence.

The design intentionally has one gameplay path. Optional bait changes which already-eligible fish are more likely; it adds no second minigame. The plugin does not include a second cast timer, custom durability, stamina, tension, release mechanics, treasure, tournaments, upgrades, or a dynamic market.
